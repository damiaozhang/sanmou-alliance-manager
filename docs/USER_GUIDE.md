# 三谋同盟管理助手：玩家使用指南

本指南按当前源码中的页面和按钮名称编写。安装包可在[下载页面](https://github.com/damiaozhang/sanmou-alliance-manager/releases/latest)获取，目前支持 Windows 10 / 11（64 位）。

游戏玩家账号无需同盟管理权限。只要在游戏中登录目标同盟里的任意一个账号，就可以扫描采集；游戏内的同盟权限与 Windows 管理员权限是两回事。

## 先建立数据工作区

首次打开助手，在「总览」创建工作区，填写名称、区服、赛季和同盟信息。已有工作区可在顶栏切换。

数据工作区用于区分同盟台账和统计，例如不同赛季各建一个。采集进行中先结束采集，再切换工作区。

## 记录同盟成员、设施和日志

1. 启动游戏并进入自己的同盟界面。
2. 在助手中选择数据工作区，打开左侧「同盟快照」。
3. 点击「采集同盟数据」。
4. 在游戏中打开或刷新同盟成员、日志、设施等相关界面。
5. 采到数据后，单次采集会自动停止；在「采集记录」检查结果。
6. 打开「同盟数据」查看成员、设施、日志、辎重等信息。

同盟快照与战报抓取是两个独立入口。成员信息为空时，先确认当前工作区已有成功采集记录。

## 连接游戏并抓取战报

1. 打开左侧「战报抓取」，进入「采集连接」标签页。
2. 在「第一步采集设置」填写采集输出目录名称，改动后点击「应用目录」。
3. 在「第二步连接游戏」刷新进程，选择游戏进程，一般包含 `nslg`。
4. 保持「被动采集」，点击「连接」。
5. 在游戏里打开单场战报详情，等待报告生成；在「战报库」选择报告，再看「战报详情」。
6. 需要同盟战报时切到「同盟战报」，点击「开始监听」，随后在游戏中打开同盟战报列表并手动翻页、展开连战分组。

**采集输出目录与数据工作区是两个不同设置。** 前者决定战报文件放在哪个目录；后者决定台账、阵容统计归属哪个工作区。连接前核对两处选择。实际输出位置显示在「采集连接」页面的「目录」一行，不必猜测硬编码路径。

助手监听游戏已经产生的数据，列表没有翻页或详情没有打开时，可能收不到新战报。结束时点击「断开」。

## 查看统计和导出

- 「阵容中心」：查看阵容、胜率和对阵情况。
- 「时间对比」：选择历史时间窗口，查看前后变化。
- 「战报时间线」：按时间浏览已记录的战报。
- 「同盟战报」中的导出操作：将相应记录保存为 CSV 等文件。
- 台账导出：根据页面提供的操作导出 JSON、CSV、HTML 或 XLSX；导出位置可在「设置」调整。

只采到少量战报时，统计样本也会很少。结果用于比较已采集记录，计算规则见[统计口径](STATISTICS.md)。

## 备份与分享

在「设置」中备份数据；恢复前先保存当前数据，并阅读页面的确认提示。

备份、导出表格、截图、原始战报和诊断日志可能包含玩家信息。不要直接上传完整数据库或原始采集包；反馈问题时尽量用虚构样本复现，并遮盖玩家名、同盟名、坐标和个人路径。

## 常见问题

**看不到游戏进程或连接失败**：确认游戏已经启动，刷新进程列表；仍失败时关闭助手，以管理员身份重新运行，并查看「设置」里的诊断信息。

**连接后没有战报**：回到游戏打开详情或翻页，确认选中了正确进程。空会话只能说明没有生成报告，需要结合操作和日志判断原因。

**同盟数据和战报没有出现在预期工作区**：核对顶栏数据工作区及战报采集输出目录，这两处相互独立。

**扫描后没出数据**：在游戏中重新打开或刷新对应界面，多重试几次采集；仍无数据时，关闭助手，以 Windows 管理员身份打开后再试。

**浏览器预览能打开但连不上游戏**：浏览器预览只展示模拟数据，采集需要 Windows 桌面安装版。

**CSV 显示乱码**：在 Excel 或 WPS 中按 UTF-8 编码导入，避免直接打开时被错误识别。

**仍无法解决**：到[问题反馈](https://github.com/damiaozhang/sanmou-alliance-manager/issues)提供 Windows 版本、助手版本、操作步骤和脱敏后的错误信息。
